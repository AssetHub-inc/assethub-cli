---
name: reference-region-topology
description: Transfer the native polygon connectivity of an explicitly matched region to a target surface and measure displacement.
---

When the user provides a sample and asks for regional topology repair, identify both actual meshes, units, side, intended anatomical landmarks and protected neighbors. Work on copies. This executor handles disk-shaped patches with one matched boundary; partition an eyelid, mouth, joint or garment into such patches only when the seam landmarks are independently identifiable. Holes, unequal boundary counts and ambiguous landmarks require another correspondence or manual review. Never select a patch by vertex count alone.

Use a geometry-only OBJ analysis copy with positive vertex IDs, one v record per vertex and native f records. Obtain native polygon loops before triangulation. Keep the original materials, UVs, skin and blendshapes in the authoring scene. A GLB already triangulated cannot establish the original quad layout. A changed OBJ is a geometry trial only.

Create a JSON manifest using zero-based native OBJ indices. Each side's faces select the entire patch; its boundary lists every boundary vertex in face-winding order, with matching starts and semantic landmarks at corresponding offsets. Alternatively, give group (the OBJ face-group name) and anchor (one corresponding boundary vertex index). The executor finds the complete oriented rim in each mesh. Validate a second semantic landmark independently before treating the inferred pairing as production evidence. Use the same coordinate units in both analysis exports. Choose maxSurfaceDeviation from the asset's actual dimensional tolerance. Example for a simple patch:

    {"region":"left elbow","units":"cm","maxSurfaceDeviation":0.05,"reference":{"file":"sample.obj","sha256":"<digest>","faces":[0],"boundary":[0,1,2,3]},"target":{"file":"target.obj","sha256":"<digest>","faces":[0,1],"boundary":[4,7,9,2]}}

Run headless Blender with --background --factory-startup --disable-autoexec --python-exit-code 2 --python repair.py -- request.json new-result-directory. The local AssetHub CLI entry is mesh-review repair-region --manifest request.json --out new-result-directory. Use a fresh output per attempt. The receipt records mapped face cycles, fixed seam vertices, protected faces and the bidirectional distances from face-triangle vertices, edge midpoints and centroids to the other mesh's triangle surface, in the declared units. These sampled distances do not bound every point. A rejected candidate is removed. Report unknowns and never call an untested pose or missing image overlay a pass.

Inspect curves, pole placement, normalized joint-loop spacing, topology under subdivision, and held-out poses for the named region. Verify UVs, rigging and materials on a cleanly reopened native candidate before production handoff. A geometry trial alone always returns needs_review.


For a region-specific verdict, freeze the measurement before edits. Record loop coverage as comparable / requested landmarks; a missing correspondence stays unknown. Measure loop spacing as signed axial offset from the joint center divided by adjacent segment length. At branches record vertex valence, cyclic order of outgoing strips and their anatomical destinations. Report the distribution and maximum of symmetric surface distances and identify the worst sample. Document native units; never compare a normalized spacing error to millimeters. During held-out poses inspect eye closure / mouth opening, shoulder elevation, finger flexion / opposition, or knee flexion, as applicable. Record intersections, contact gaps, local stretch and protected-surface movement. Only static patch connectivity, sampled surface distances and fixed boundaries are automated by this executor.

For existing quad meshes with joint-driven support rings, set method to joint_ring_spacing, provide maxVertexDisplacement in declared mesh units, and specify joints on both reference and target. Each joints entry uses the same semantic joint name and three XYZ triplets (previous joint, center, next joint) in the mesh frame. Select the patch by group or faces. This path uses repair.py and joint_rings.py and preserves face connectivity. It locates complete transverse edge cycles winding around the bone axis, measures nearest proximal and distal ring offsets divided by shorter adjacent bone length, and only keeps bounded moves improving a measured side without regressing the others. Shared vertices with protected neighbors are locked. Report comparable versus requested coverage; missing rings and winding ambiguity remain unknown. The receipt includes moved count, median displacement among moved vertices, maximum displacement, and normalized errors for each side. The transfer_patch method handles connectivity changes.
